What's New

New Features

  • Added a Connections pane for MCP connectors. It has a catalog of connectors, custom connector support, suggested connectors, and OAuth sign-in. Connectors are written to your CLI agents' configs, and credentials are kept in the Keychain.
  • Any MCP-capable agent can now connect to and control Addy, including agents outside Addy. A new Connected Agents settings section lets you manage them, with approval prompts for sensitive actions and folder grants, per-agent tool policy presets, an audit log, and optional remote access through a cloud relay.
  • Addy's browser can now save and autofill website passwords. A save prompt appears after you sign in, saved logins are stored in the Keychain behind a vault lock, and a Passwords window lets you view and manage them. You can also import logins from elsewhere.
  • Figma links now open in the Figma app instead of Addy's browser.
  • Claude Code memories are now imported into Addy's memory store, and Claude's own memory is turned off so there is one source of memory.
  • Prompt attachments now appear in Addy Mobile transcripts.

Improvements

  • Addy's rules and guide are now delivered to each agent session instead of being written into global CLI config files for Claude, Codex, Cursor, Grok and Antigravity. Your global CLI instructions are no longer modified, and legacy global entries are handled.
  • The Addy MCP tool set was reduced from 87 to 67 tools, so agents have fewer tools to choose from.
  • Addy's MCP server instructions now fit within Claude Code's 2,048-character limit, so they are no longer cut off.
  • Chat content previews now keep their full width.

Bug Fixes

  • Browser dialog cards no longer disappear when you click one of their own buttons.
  • Cloud MCP sign-in now completes when Addy is served under a URL path prefix.
  • Sensitive form fields are now redacted in the browser network log.

Internal Changes

  • Added a shared Keychain store for per-account secrets.
  • Releases are now built and published automatically on every push to main.
