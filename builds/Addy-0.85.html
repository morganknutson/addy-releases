What's New

New Features

  • The code editor is now a full IDE-style editor. It adds code folding, a minimap, multiple cursors, snippets, inline Git blame and a Find in Files panel.
  • The editor also gains a quick picker with fuzzy matching, code completion and language-server editing features, back/forward navigation history, and handling of file encodings and line endings.
  • Addy now requires an Addy account in release builds. You sign in during onboarding through a new account step.
  • Connected Agents settings has new Connect buttons for Claude and ChatGPT that set up the connection for you.
  • Addy Mobile shows addy://conversation/… links in chat as conversation cards. Tapping a card opens that conversation, as clicking it on the Mac does.

Improvements

  • Connected connector cards use a two-row layout. The Connections pane now shows CLI logos and normal-size buttons.
  • Adding a connector now replaces a hand-added MCP server of the same name instead of conflicting with it.
  • The theme preview cards now draw empty panes.
  • Grok's multi-line args arrays in MCP config are now read correctly.

Bug Fixes

  • Connector sign-ins keep working after the Keychain move, so you no longer have to reconnect.
  • Fixed the wide gap after bullets on nested list items in chat messages.

Internal Changes

  • Removed DeepWiki, Cloudflare Docs and Exa from the connector catalog.
  • The Settings sidebar is now built from a single list of pages.
