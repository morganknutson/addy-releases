What's New

New Features

  • Orchestration task cards have a new Ask button, which appears when you hover over a card. It opens a chat agent next to the Orchestration pane that reads the task's worker logs, reports, review findings, failing checks, history and pull request, then tells you what the task is doing, whether it's stuck or needs you, and what will likely happen next. The agent only looks and reports; it doesn't edit, push, merge or change the task.
  • Playbooks can now ship a release when their work merges. Turn on "Ship a release after merging" in a playbook's shipping rules and Addy adds a release marker ([release] by default, customizable under "Release marker") to the merge commit's subject, so a release workflow watching the base branch can pick it up. This works with squash and merge commits but not rebase, since a rebase creates no merge commit.

Improvements

  • When releases are on, the playbook's summary line reads "ships a release". Playbooks and in-progress tasks saved before this option existed still load, with releases turned off.

Bug Fixes

  • Fixed a crash (SIGABRT) that could occur at launch while Addy checked provider status and usage limits. These checks still run in parallel, but the conditions that caused the crash are gone.
