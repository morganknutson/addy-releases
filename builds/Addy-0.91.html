What's New

New Features

  • Addy can now record content-free session replays: layout, focus, agent states, clicks, overlays and activity counts. It never records text, keystroke characters, paths, titles or commands. Chunks are compressed and uploaded in the background so you can keep working.
  • Replays now include the pointer path. The pointer is sampled at up to 15 times per second, only while it moves and Addy is the active app. This doesn't change hover behavior in any view.
  • Telemetry batches now carry a session ID, so telemetry can be matched to the replay from the same app launch. Shortcut use and incident marks appear in the replay as events with no properties.

Improvements

  • Setting ADDY_TELEMETRY_DISABLED=1 now turns off session replay along with telemetry.
  • Replays can be switched off remotely. If the server answers that recording is off, Addy stops recording and deletes any pending replay chunks.
  • A replay left behind by a crash or force quit is closed out on the next launch, so it still ends cleanly.
  • Setting ADDY_TELEMETRY_ENDPOINT points telemetry and replay uploads at a local server for development.

Internal Changes

  • Replay and telemetry uploads now share one authentication path.
  • Added test coverage for replay encoding, keyframes, live upload, main-thread safety, pointer sampling and the remote off switch.
