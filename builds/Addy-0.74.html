What's New

New Features

  • Press Cmd+T to open a new terminal pane. Hold Cmd+T and press an arrow to place it in that direction, and add Shift to span the whole workspace. Releasing without an arrow opens it to the right, the same as Cmd+D.
  • Drag the pane strip sideways by holding the middle mouse button (scroll-wheel click) over it. A plain middle-click still works on tabs and links, and the release after a drag is ignored so it doesn't open a link.
  • Settings → Interface has a new "Agent link plug" toggle. Turn it off to hide the plug button in agent pane headers and disconnect any existing agent links.
  • Settings → Interface has a new "Workspace layout" card. It shows a Grid or Scrolling columns preview to pick from, replacing the old "Scrolling columns" switch.

Improvements

  • Directional split rows in Shortcut settings now show their held chord (for example "⌘D + ↓") instead of "Not Set". The chords update when you remap ⌘D or ⇧⌘D.
  • The shortcut help text in Settings now covers the ⌘T new-terminal gesture.
  • "Reopen Closed Pane" moved from Shift+Cmd+T to Ctrl+Cmd+T so Cmd+T is free for new terminals.
  • The chat restore placeholder now shows only the logo, without the "Loading conversation…" text.
  • Project names in the sidebar have a little more space next to the icon.

Bug Fixes

  • Fixed a crash in the file explorer when files in the project root changed while the tree was open.
  • The focus glow around the active pane now follows the pane when splits are inserted, resized, or moved.
  • Removed the Command-held vertical scrolling that turned mouse-wheel motion into sideways strip scrolling.
