What's New

New Features

  • Onboarding has been redesigned as a full-window takeover with a step indicator, header and footer. It now includes in-app sign-in to your Addy account using an emailed one-time code.
  • Onboarding gained an Interface step, where you choose your layout, and a Project Import step. The import step discovers Git projects on your Mac so you can add them right away.
  • The Manual has been rebuilt with a hero page, illustrated scenes and topic pages. It has a searchable outline for jumping to any topic.
  • You can now select several worktrees at once in the sidebar and act on them in bulk.
  • The project header now stays pinned at the top of the sidebar while you scroll through worktrees.
  • A new Servers menu in the header shows the project's servers through a pill button.

Improvements

  • Servers now belong to the project rather than to individual panes, so they stay consistent as you move between panes and worktrees.
  • Telemetry batches are now attributed to the Addy account you're signed in with.
  • Onboarding tool rows for GitHub, agent CLIs and your account have been refreshed. The Settings layout options now share the same layout picker views as onboarding.
  • Action buttons and the server footer bar now use a shared spinning-symbol indicator for in-progress states.

Internal Changes

  • Added tests for onboarding, email-code sign-in, telemetry, the Manual content, sidebar selection and the sticky header.
