What's New

New Features

  • Bring outside MCP servers into Addy. The Connections pane has a new "Found in your CLIs" section. It lists MCP servers you set up yourself in Claude Code (including per-project servers), Codex, Cursor and Antigravity, and shows which CLIs each one is in. Click "Bring into Addy" to share a server with every CLI. Catalog servers are recognized so they get their logo and proper sign-in, and existing tokens and tool names carry over.
  • More than one connection per connector. You can connect a connector several times, such as two Linear workspaces or a work and a personal GitHub account. Each connection gets its own name (for example "Linear · Acme"), credential and server name, so agents can use them side by side.
  • Custom appearance mode. Settings → Appearance now has four modes: System, Light, Dark and Custom. Custom lets you pick any background color from a hue/lightness spectrum. Addy chooses light or dark styling to match the color, and the rest of your theme adapts to it.
  • "Always pop out browser" setting. When this is on, the browser opens in its own window instead of docking in the workspace. The window remembers where you put it, even after a relaunch.
  • Claude Code's AskUserQuestion is answered in Addy. When Claude Code asks you a question, its question card now waits for your answer and sends your choice back to the agent. Before, the question expired after a few seconds and Claude reported that you hadn't answered.
  • Stuck builds and commands are stopped automatically. Build and command panes started by agents are now stopped if they hang with no output and no CPU activity, or if they wait too long on another process's SwiftPM lock. The agent is told why the command was stopped and which process held the lock.

Improvements

  • Agents are told when their last turn was stopped. The agent's next prompt explains whether you pressed Stop, an urgent message interrupted it, or a tool hit its time limit. As a result, agents no longer mistake "Exit code 137" or "Killed" for a crash or an out-of-memory error and retry it automatically.
  • Pushing a divider collapses grouped columns one at a time. The column nearest the divider closes first, and panes that can't collapse are skipped instead of stopping the push. Columns now preview snapping shut while you drag.
  • More reliable rails
  • Rails now follow the direction of the split they're in.
  • Double-clicking reliably expands a rail.
  • Collapsed columns stay shut when room comes back.
  • Server panes can now be collapsed to a rail.
  • Theming overhaul. Most parts of the interface now have their own theme colors, fonts and spacing, so the theme editor can style them individually. Theme changes also apply faster across the app.
  • Blend modes work on real colors. Theme blend modes such as Multiply, Screen and Overlay are now calculated against the colors actually behind each element, so they show up correctly on fills, borders and text.
  • Browser pages follow your theme. The browser's start page, error pages and paused pages now match your light, dark or custom theme and update immediately when it changes.
  • Live illustrations. The manual and What's New illustrations are now live scenes drawn from Addy's actual interface instead of static drawings.
  • What's New pill shows the version. The pill now displays the version number, and the label above the title was removed.
  • Smaller fixes
  • The theme editor's search field and the agent pane footer buttons were restyled to match the rest of the app.
  • The agent chip's robot icon was resized and aligned with the text around it.

Bug Fixes

  • The sidebar now stays at the width you drag it to instead of snapping back to its maximum width when you release the divider.
  • Fixed layout issues where panes could be squeezed too small, or the layout could settle in the wrong place after a resize.
  • Running tests no longer writes to the app's log file or deletes it during rotation. Addy also reopens its log if another process replaces the file, so log lines are no longer lost.
