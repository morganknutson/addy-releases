What's New

New Features

  • Added Cursor, Grok, and Antigravity as CLI backends, with sign-in, model discovery, update checks, and streaming chat support for each.
  • Chat messages can now link to other conversations. Linked conversations appear as clickable cards, and agents can create these links through new tools.
  • Conversation search now looks inside conversation content, not just titles.
  • Permission requests now send a notification, including a push to Addy Mobile. The request card also shows how long it has been waiting.
  • Addy Mobile's browser pane can show a phone-sized page with an iPhone user agent, rendered on the Mac beside the desktop view. Tapping a text field now reports back whether the page has a field focused.
  • Chat now has a new animated Addy logo for the restore screen.
  • Added a strip of pane tabs to the split-pane layout, with new layout handling in the split pane view.
  • Markdown blockquotes in chat now draw a continuous rounded bar beside the quoted text, including across wrapped lines.

Improvements

  • Settings has been substantially reworked, with a new layout and rows. Theme selection is now done in Settings and the Theme editor, with a new theme snapshot preview.
  • Signed-out CLIs now show a single sign-in card instead of repeated errors. The card spans the chat column with more padding, and the stall toast is quieter.
  • Agents can no longer switch the project you are looking at. Their requests to change the visible project are refused.
  • Chat activity cards stay full width when they show pane buttons, instead of shrinking to the button's title.
  • The Addy app icon and dev icon have been refreshed, and 1024px iOS icon exports were added.
  • Chat timestamps now have consistent margins, and user message rows use the same spacing as assistant rows.
  • Chat scrolling now follows new content more reliably.
  • Updated the bundled model catalog and theme defaults.

Bug Fixes

  • Fixed a deadlock between iCloud sync and the main thread that could freeze the app.
  • Fixed a crash when a backend reused a message ID across turns and appended blocks out of order.
  • The auto-compaction setting is now reset to off once if it was left on from an earlier version.

Internal Changes

  • Removed the Gemini CLI backend, its stream parser, and its terminal conversation adapter.
  • Release builds are about 9 minutes faster, release-note formatting was fixed, and old update archives are now pruned from the update feed on every release.
