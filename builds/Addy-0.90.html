What's New

New Features

  • Added a "What's New in Addy…" item to the Addy menu. It opens a spotlight window that walks through the newest features, and it also appears automatically at launch when there is something new. It stays disabled while no spotlight is available.
  • Feature pages in the What's New window can link straight to the matching topic in the in-app manual.
  • Admin accounts get a "What's New Drafts" submenu in the Addy menu. It lists unpublished drafts from addy.land so they can be previewed in the app. Drafts with errors are shown greyed out with the issue count, and drafts that edit a published entry are marked "(changes)".

Improvements

  • Main-thread freezes are now reported once they last 2 seconds instead of 5. Shorter beachballs that never reached telemetry are now captured.
  • A freeze is reported as soon as it crosses the threshold, so hangs that end in a force quit are still recorded. When the app recovers, it logs the total freeze duration against the same hang.
  • Addy now finds command-line tools such as the agent CLIs by checking common install folders and your login-shell PATH. It no longer starts a login shell for each lookup.

Bug Fixes

  • Fixed multi-second freezes when Addy looked for a CLI that isn't installed. On Macs with a slow shell startup file, each lookup could block the app for up to 7 seconds, including during Settings refreshes.
