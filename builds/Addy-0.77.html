What's New

New Features

  • Images returned by Claude's tools now appear inline in chat, and markdown image paths that point to local files load in the message.
  • Addy Mobile's agent menu gained four actions: New Agent with Context, Connect Worktree, Grant Folder Access, and Rename.
  • Addy Mobile also shows connected worktrees and favorited branches in the project list.
  • Signing in to Addy is no longer limited to GitHub. The sign-in page now offers Apple, Google, GitHub, an email code, or email and password.
  • The sign-in prompt now reads "Sign In" and invites you to "sign in or create a free account".
  • You can try the account gate on a single Mac before it ships to everyone. Run defaults write com.morganknutson.Addy AddyAccessGateOptIn -bool YES to turn it on. The opt-in only works against the production service, and it can't switch off a gate that the app bundle already enables.

Improvements

  • The pairing constellation has a new look. It is drawn as white, softly glowing dust, and the old "petals" style is replaced by an atom with electrons on tilted orbits. It animates in step on the Mac and the phone, so a mismatched code is easy to spot.
  • The constellation is larger in the pairing approval panel.
  • Sync Now builds its local inventory faster.
  • Sync now writes its system-field records in fewer, coalesced batches rather than rewriting them after every batch.

Bug Fixes

  • Queued layout changes now resolve by record name, and layout saves for layouts that no longer exist are dropped. Previously these could be stuck in the sync queue.

Internal Changes

  • Chat activity transitions are now logged under [ACTIVITY] to make diagnosing busy and idle state changes easier.
