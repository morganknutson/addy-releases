What's New

Addy Mobile remote access

  • a new host lets the Addy Mobile app connect to your Mac. It can pair with nearby phones automatically, or reach Addy from anywhere through the addy-relay service, with push notifications.
  • Addy Mobile mirrors the Mac's chat presentation. It can also open the Browser, Code Editor, Conversations, File Explorer, Git, Memory, Notepad, Plans, Project Health and Test Runner panes.

Chat browser tabs

  • the browser pane now supports tabs, and agents open pages in the browser you can actually see.
  • File paths in chat messages are now clickable.
  • Code blocks and tables in chat can be popped out into a preview panel.
  • Onboarding is now a two-page floating setup window.
  • Settings now covers CLI install, update, sign-in and integration health. Sign-in is also available directly in chat.
  • The theme system was overhauled and the Theme Editor rebuilt.
  • Settings has a new "Show Footer" option.
  • Addy discovers Gemini models through ACP.
  • Agent spawning is split into three tools: spawnagent, spawnsubagents and spawnterminal.
  • addystartserver is now idempotent. A new server ledger tracks servers that agents have started.

Improvements

  • Split a pane by holding Cmd-D and pressing an arrow key. The rail toggle moved to Opt-R.
  • Rails, divider drags and the layout solver were reworked.
  • Chat spacing is unified, and pane chips look like buttons.
  • Queued message cards, tool groups and tool cells in chat were redesigned. Error views now explain more.
  • Settings was reorganized into cleaner cards, with refined model guidance.
  • The Project pane layout and command previews were polished.
  • The chat reader stays in place while an agent streams a response.
  • Popped-out panes and the split layout handle pop-out changes more reliably.
  • The onboarding window stays visible when Addy isn't the active app.
  • The app icon now uses Icon Composer icons.
  • Selected settings, voice, text-to-speech, auto-compaction and dev-only panes and shortcuts are limited to debug builds. Release builds no longer show them.
  • The default model no longer auto-starts.

Bug Fixes

  • Sub-agent panes no longer shrink based on their position in the stack.
  • Release launches no longer rewrite the auto-compaction setting to off.
  • Duplicate pending iCloud (CloudKit) changes for the same record are now merged.
  • "Mark Layout Jank" appears only when layout tracing is on.

Internal Changes

  • Releases are now built, signed and published from GitHub Actions. Release notes are written by Claude in CI.
  • The build falls back to checked-in .icns icons when actool can't compile .icon files.
  • Added pane layout trace logging.
  • Added theme tokens for the scroll button shadow and sidebar radii.
