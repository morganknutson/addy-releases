What's New

New Features

  • Addy Mobile can now manage your projects from the phone. It can add an existing folder, create a new project (the folder is created and git inited, and an agent starts that asks what the project is for), clone a Git repository, rename a project, set or reset its sidebar icon, and remove a project. These actions don't switch the project showing on your Mac.
  • Addy Mobile can now manage branches. It can star or unstar a branch, hide branches from the sidebar and bring them back, and remove a branch worktree along with its branch. Removing a branch that has uncommitted changes fails with a warning unless the phone confirms the removal.
  • Dev server panes show up on Addy Mobile with their status (starting, running or stopped), command and URLs, plus Stop and Restart buttons like the Mac footer. A server pane no longer shows a prompt box on the phone.
  • Addy Mobile can choose which push notifications it receives: agent questions and permission requests, finished turns, and errors. Phones that haven't chosen still get all of them.
  • Addy Mobile now shows the default folders where new projects and clones are created. It also shows each project's hidden-branch count and a logo for each model's CLI (Claude, Codex, Cursor, Grok).

Improvements

  • A colored agent pane now washes its body, header, footer and chat background with its color, subtly in both light and dark appearances. The tint follows theme changes and matches Addy Mobile.

Bug Fixes

  • Images linked from a chat to the phone are now found when their paths contain spaces or parentheses. This covers percent-encoded spaces such as Island%20(compact).png and paths wrapped in angle brackets.

Internal Changes

  • Remote protocol bumped to version 11 for the new project, branch, server and notification messages.
