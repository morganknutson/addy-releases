What's New

New Features

  • Browser panes now have find-in-page (Cmd+F), with Cmd+G and Shift+Cmd+G to jump to the next and previous match. A search bar appears at the top right of the pane.
  • Browser panes can print the current page with Cmd+P.
  • Cmd-clicking or middle-clicking a link in the browser opens it in a background tab. Browser panes also support swipe navigation.
  • The browser address bar now autocompletes from your history and bookmarks. Suggestions appear in a dropdown, and the best match is completed inline as you type.
  • A new History window (Addy menu → History…) lets you search, open and delete visited pages. It also has a clear-browsing-data option that removes history, cookies and cache.
  • The browser blocks third-party ads and trackers by default. It only blocks requests to well-known ad and analytics hosts, so sign-in and site functionality aren't affected.
  • A project that synced from another Mac and has no local folder yet, or whose folder is missing or empty, now offers a one-click restore. It clones the repository into the right folder, or adopts a repository you already cloned by hand.

Improvements

  • The access gate now looks like onboarding. When you're signed out, it shows onboarding's sign-in step inside the gate.
  • If a chat message was rejected because the CLI was signed out, signing back in restarts the chat process and resends your unanswered message automatically. Sending a new message replaces the rejected one.
  • A failed repository clone now explains what went wrong. It offers "Sign in to GitHub" when GitHub reports a missing or inaccessible repository, "Accept License" when the Xcode license hasn't been accepted, and a hint to paste a full URL when the address isn't a repository.
  • Opening a chat for a project whose folder is missing now says so and explains how to fix it, instead of showing a bare "file doesn't exist" error.
  • Browser sign-ins are now shared across every project, so logging in to a site once carries over everywhere, as in a normal browser. This also helps auth-heavy sites such as Apple Developer.
  • The browser viewport now always renders on white, regardless of theme. Pages without their own background, such as App Store Connect, no longer show unreadable dark-on-dark text.
  • Plan baselines and review diffs now include untracked files, so files that existed before a plan started are no longer mistaken for files the plan created, and new files an agent adds show up in its review.
  • Long project and worktree names no longer widen the sidebar.

Bug Fixes

  • Fixed browser slowdowns on pages. The DialKit bridge script now loads only when DialKit is available, and the content-security-policy watcher stops once the page head has loaded instead of observing the whole document.
  • Starting a plan no longer freezes the window in large repositories. The baseline snapshot now runs off the main thread, and clicking Build twice can't start the plan twice.
  • If an agent can't launch after you click Build, the plan returns to its previous state so Build is offered again.
