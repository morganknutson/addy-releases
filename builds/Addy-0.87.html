What's New

New Features

  • Agents can now use a browser pane in a project you aren't viewing. Screenshots, JavaScript evaluation, console access and other browser tools work there without switching your project, and agents are told to report that the page is in that project rather than on screen.

Improvements

  • Connector logos are now bundled with Addy instead of being downloaded from each service's website. They appear instantly and offline, as a single-color white logo on a tile in the connector's brand color. Bright brand colors are darkened just enough for the logo to stay legible. Custom connectors still show their initial.
  • The ••• button on connected connector cards is now an icon-only button without a dropdown chevron. It opens its menu on click and has a "More actions" accessibility label.

Bug Fixes

  • A browser pane that was unloaded to save memory in a project you're not viewing now reloads when an agent uses it, and it stays loaded while the agent keeps working.
