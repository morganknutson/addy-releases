What's New

Voice input

  • Addy can now transcribe your microphone into the prompt locally. Press ⌥1 or tap the mic button in the chat input to dictate; enable it under Settings → Voice, where you can also download the local transcription model.
  • Text-to-speech — Assistant replies can be read aloud with a local voice. Each assistant message gets a play button, and an optional setting speaks completed replies automatically. Speech streams in buffered chunks so playback starts sooner, and you can pick a voice and download the local speech model from Settings.

Connect agents

  • Link two agent chat panes by dragging a cable from one pane's plug icon to another's socket, so the agents can pass messages directly to each other. Relayed messages appear as agent-to-agent cards in the chat, and a "Connected to Agent" notice confirms the link.

Pane color tags

  • Right-click an empty area of a pane's footer to tag it with a color, shown as a colored border around that pane's chat input for quick visual identification.

Improvements

  • The workspace footer bar moved to a header at the top of the workspace; the toggle shortcut is now ⌃⌘. ("Toggle Header").
  • Queued messages now stack vertically in the input area instead of scrolling in a horizontal carousel, so pending messages are easier to see at a glance.
  • ⌥1 now starts voice input in the active pane (the previous ⌥1–⌥9 pane-focus shortcuts have been removed).
  • Local speech models now download as split zip archives with a clearer download and setup flow, and text-to-speech uses a higher-quality 1.7B voice model.
  • Voice settings are now honored consistently across the chat controls.
  • addyruncommand now runs in owned subpanes, and subpane navigation arrows are hidden for a cleaner layout.

Bug Fixes

  • Fixed stale Git change attribution so the agent or pane credited with a file change is tracked accurately across concurrent operations; also fixed the attribution label that could show raw placeholder text instead of the mode and pane ID.
  • Fixed queued messages stacking incorrectly in the input area.
  • Fixed universal (Apple Silicon + Intel) release packaging so the shipped app bundle is built correctly.
