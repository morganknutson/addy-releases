What's New

New Features

  • Reviewer standards (design, engineering, product documents) now sync to CloudKit alongside plans, memories, and other project data — your review criteria carry across devices automatically

Improvements

  • Browser JavaScript instrumentation now runs in all frames including iframes, not just the main page — console logging and error capture are more comprehensive for apps with embedded frames
  • Architecture description generation gracefully skips when the required AI CLI tool is not installed, instead of attempting to run and failing silently
  • Memory items and the memory index are now sorted alphabetically within each type group instead of by most-recently-updated, making it easier to find specific memories

Bug Fixes

  • Fixed browser loading bar occasionally showing zero-width progress when the pane is first displayed — the bar's frame is now laid out before computing the progress width
  • Fixed incoming CloudKit project context changes triggering another outgoing sync write, which could cause unnecessary sync churn
  • Fixed agent pane footer bar triggering Auto Layout constraint evaluation while the view hierarchy was still being assembled, which could cause layout warnings
  • Fixed the Conversations pane appearing in the pane launcher for production builds — it has been returned to debug-only while still in development
  • Fixed chat scroll-to-bottom causing multi-second hangs on long conversations by scoping the layout pass to just the scroll view's document instead of the entire view subtree
