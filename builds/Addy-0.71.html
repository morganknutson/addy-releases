What's New

New Features

  • Connect a worktree to every agent in a project. Right-click a worktree in the sidebar and choose "Copy Worktree", then pick "Paste Worktree" from any pane's context menu — or use "Connect Worktree…" to pick one from a new project/worktree sheet. The connection persists, grants folder access automatically, and is injected into the context of every current and future agent in that project.
  • Agents can manage this themselves through three new tools: addylistworktrees, addyconnectworktree, and addygrantfolder_access (which grants a single agent pane access to a folder outside its project and relaunches it with native workspace access).
  • Rename Project… was added to the sidebar context menu. It renames the project inside Addy only — the folder on disk is untouched.
  • Pasting a GitHub branch URL (github.com/owner/repo/tree/branch) into "Add Github Repository" now clones that branch directly, and Addy remembers the parent directory you last cloned into instead of always defaulting to ~/Developer.
  • Chat conversations now sync over iCloud, alongside sidebar project order, worktree branches, favorite branches, and repository scope.
  • Settings → iCloud gained a progress bar and a Sync Details card that compares both sides: how many records are on this Mac versus in iCloud, broken down per project and record type into uploads, downloads, differences, and deletions, plus queued/retrying/blocked counts.
  • Agents can now request a hard interrupt when messaging another agent (deliverypolicy: interruptactive), which stops the target's active turn and cancels its blocking review, test, build, or sub-agent work before delivering the message. Ordinary messages remain non-preemptive.
  • A plan review you start from the Plans pane now runs to completion on its own: if it finds critical or warning issues, a visible "Fix: <plan>" chat agent opens, updates the plan, and requests another review, looping until the plan passes.
  • Right-clicking a link in a chat message adds Open in Default Browser alongside Copy Link, and clicking an image file path in a chat message opens it in an image preview panel.
  • The chat input now supports undo and redo (Cmd+Z / Shift+Cmd+Z).

Improvements

  • When an agent in one project tries to switch or activate a different project, Addy asks first with a "Switch Project" / "Stay Here" prompt from the window you're actually looking at, and tells the agent not to retry if you decline.
  • addyopenurl and browser screenshots now report which pane and project they targeted and whether it is actually on screen, so an agent can no longer tell you it opened a page you cannot see. Screenshots can also target a specific browser pane.
  • Dragging or pasting attachments into chat now imports them in the background with fast thumbnails; the send button stays disabled and shows "Preparing attachments…" until they're ready, so large images no longer freeze the window.
  • Scrolling back through a chat holds your place when new messages arrive: a live scroll always wins over auto-follow, and only messages you send yourself jump the view back to the bottom.
  • A browser pane that is hidden, in an inactive project, or detached from a window now unloads its page to release memory (and does so immediately under system memory pressure), restoring it when you come back to it.
  • Code editor shortcuts like Cmd+W and Cmd+S only apply when the editor actually has keyboard focus, so an open editor pane no longer hijacks Close Pane for the whole window.
  • Generating a commit message now explains failures with a toast instead of silently doing nothing — separate messages for unstaged changes, no Helper model configured, usage limits, sign-in required, a missing CLI, and being offline.
  • Truncated pane names now refresh their tooltip when a pane is resized or renamed, not just on layout.
  • Sidebar right-click menus are now native macOS menus that open at the pointer instead of a popover anchored to the row.
  • Popped-out and hidden panes no longer hold an invisible slot in the split layout, which removes the sliver artifacts and makes hide, reveal, and pop-out re-layout faster.
  • Chat rows are reused without being torn down and rebuilt, and very large messages skip an expensive width measurement pass, so long transcripts scroll and resize more smoothly.
  • Review pane dropdown buttons are larger and easier to hit, and the light theme's chat cards, input field, and user bubbles were lightened.

Bug Fixes

  • Connected worktrees are no longer dropped when projects are saved during normal use or at quit.
  • Fixed streaming chat updates being applied to the wrong message when the transcript shifted mid-response.
  • Stopping and immediately resuming a Claude chat session could leave two processes running against the same session; the old process is now retired before the new one starts, and stale termination callbacks are ignored.
  • Encoding images and writing large messages to a backend moved off the main thread, fixing UI hangs when sending big attachments.
  • Pending iCloud changes now live in a crash-safe journal, so unsent edits survive a restart and an older upload can no longer acknowledge a newer local edit or overwrite it.
  • Conflict resolution preserves the server record's change tag and clears removed fields, so ordinary updates are no longer treated as conflicts and deleted values no longer reappear.
  • Switching iCloud accounts no longer applies records from the previous account, and each upload gets its own temp file so an in-flight upload can't send bytes from a newer edit.
  • Standards records are now keyed by domain and kind, so general and specific standards no longer overwrite each other in iCloud.
  • Why documents and standards sync with their real file modification dates instead of "now", and an empty project context is no longer created and uploaded for projects that never had one.
  • Layouts received from another device are saved without being echoed back to iCloud, ending a sync loop.
  • A memory deleted on another device is now applied correctly even when the local project's memory store hasn't been loaded yet.
  • Tasks now carry a modification timestamp, so an older copy from another device can no longer win over a newer local edit.
  • Hang detection uses a monotonic clock, so waking the Mac from sleep no longer reports a fictitious multi-minute freeze.

Internal Changes

  • Log messages are capped at 32 KB with a truncation marker, and chat stderr is logged as a preview, so a single huge payload can't flood the log file.
