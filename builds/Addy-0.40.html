What's New

IMPORTANT

  • New pane shortcuts are now cmd+T instead of cmd+D

New Features

  • Added a dedicated Build tool (addyrunbuild) that agents can use to run compile and build commands in their own managed pane, keeping your terminal free.
  • Agents now receive a structured runtime identity block in their prompts, giving them reliable awareness of which pane they're in, what project they're working on, and whether they're a sub-agent.
  • Added ⇧⌘C keyboard shortcut to open the Conversations pane. Tests pane moved to ⇧⌘D.

Improvements

  • Chat is now backed by a virtualized NSTableView instead of a plain stack view. Conversations with hundreds of messages scroll, resize, and stream dramatically faster without UI stalls.
  • Multiple performance passes eliminated main-thread stalls during chat resize, conversation preview loading, theme palette switching, and tool group rendering. Added a native frame-pointer backtrace sampler to pinpoint bottlenecks.
  • Owned child panes (sub-agents, reviews, tests, servers, builds) now share a unified vertical stack attached to their parent pane. Mixed stacks of different pane types render correctly, and closing a child pane properly cleans up the hierarchy.
  • The "Collapse reviews by default" setting now applies to all sub-processes — reviews, tests, and sub-agents — and has been renamed accordingly.
  • Theme picker in Settings now uses a sidebar layout with Light/Dark/System options on the left and a larger preview on the right.
  • Settings headings moved into the header bar for a cleaner look with tighter spacing.
  • Built-in model profiles now show concrete names like "Claude Opus 4.7 (Latest)" instead of generic "Latest" labels. Legacy saved profiles are migrated automatically.
  • Pasted images are now automatically downscaled to fit API dimension limits before sending, preventing agent crashes from oversized screenshots.
  • Conversations pane pagination no longer gets stuck when multiple chats are streaming simultaneously.
  • Codex chat now handles MCP elicitation requests, enabling tool permission prompts during Codex sessions.

Bug Fixes

  • Fixed chat messages being cropped or clipped at the bottom of the scroll view after restore or resize.
  • Fixed streaming text duplicating the first word or prefix during live Codex chat output.
  • Fixed thinking blocks not rendering correctly — restored the thought bubble accessory, fixed collapsed card height, and ensured expand/collapse animations work properly.
  • Fixed chat not pinning to the bottom when you send a message while the assistant is streaming.
  • Fixed streaming row heights not updating as content grows, causing text to overlap or get hidden.
  • Fixed a reentrant NSTableView crash that could occur when messages streamed in during a layout pass.
  • Fixed the Plans pane "Mark Complete" button not working — it was incorrectly requiring auto-review prerequisites.
  • Fixed git pane failing to stage files with spaces or special characters in their paths (quoted porcelain path decoding).
  • Bounded git provider process execution to prevent runaway subprocesses from hanging the git pane.
  • Fixed tool group card animations firing on the wrong cell when scrolling quickly during expand/collapse.
  • Resolved Auto Layout conflicts in the pane header bar, memory view, and expandable cards.
  • Fixed permission card deduplication in chat tool rollups so repeated permission prompts don't pile up.
  • Fixed blank chat view that could appear after switching conversations.
