What's New

Improvements

  • Language servers now start the first time you open a file in that language in the code editor, not when a project opens. Projects where you never open the editor no longer pay for a server indexing the whole workspace, and files you opened while a server was starting are passed to it once it's ready.
  • Language servers now get up to 60 seconds to finish their first start instead of 5. Slow cold starts, like sourcekit-lsp resolving a Swift package, no longer fail. A server that never finishes starting is now shut down instead of being left running unused.
  • Installing plugins now adds the official Claude plugin marketplace first if Claude Code doesn't already have it. Plugin installs no longer fail on a fresh Claude Code setup.
  • The plugin installer now finds the Claude CLI the same way the rest of Addy does and uses your login-shell environment. If an install fails or takes longer than two minutes, the CLI's output is logged.
  • The "About" picker in the Feedback window now gets a wide slot so it no longer collapses.

Bug Fixes

  • A fixed-width or pinned pane now keeps the size you last dragged it to. Previously a window resize, a layout pass or putting the pane on the rail could overwrite that size, so it sometimes reopened only 36pt wide.
  • When a layout leaves panes below their minimum width and redistributing can't fix it, Addy now stops retrying the same redistribution on every resize.
  • Addy now detects which plugins are already installed correctly by reading the current format of Claude Code's installed_plugins.json.
  • "Sync Now" on a new iCloud account no longer fails before Addy's iCloud zone has been created. It now treats iCloud as empty and syncs normally.

Internal Changes

  • Anonymous telemetry now covers clicks on the pane rail, divider drags and the layout solver's decisions, plus layouts where panes stay too narrow. These events contain only counts, pane types and outcomes, never pane names.
  • Session replays now record double-click counts and flag stuck layouts. Language server failures are now reported as separate events for failed launches, failed starts and crashes.
