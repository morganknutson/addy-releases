What's New

Improvements

  • The iCloud "knowledge items synced" banner no longer appears at the top of the workspace when project knowledge arrives from iCloud.

Bug Fixes

  • Memories now keep millisecond-precision timestamps. Before, a memory this Mac had just uploaded could come back from iCloud and be treated as a newer edit from another device. Memory files written with the old day-only dates still load and are upgraded the next time they're saved.
