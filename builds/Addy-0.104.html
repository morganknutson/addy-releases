What's New

New Features

  • Connect GitHub from inside Addy. The Pull Requests and Actions panes, failed clones, and a new GitHub card in Settings → Integrations now show a Connect GitHub button. If the GitHub CLI is missing, Addy installs it first (no Homebrew needed). It then opens GitHub's sign-in page in your browser, shows the one-time code and copies it to your clipboard, so you no longer have to run gh auth login in a terminal.
  • Retry failed clones automatically. If a clone fails because of GitHub access, the error screen now offers Connect GitHub and tries the clone again once you're signed in.
  • New one-page setup for a new Mac. A single "Setting Up Your Mac" page replaces the separate "Install Git" and "Install Agents" steps. Tools start installing as soon as the page appears, so you can keep going while they finish. Git and GitHub rows show a checkmark and disappear when they're done.
  • Setup picks up where you left off. If you quit setup partway through, it reopens at the furthest page you reached.
  • Clearer Git install during setup. Addy watches Apple's Command Line Tools installer and explains that downloading Git takes about 10 minutes. A "Show Installer" button brings Apple's window back if it ended up behind Addy.
  • Agent sign-in without a terminal. Claude Code and Codex now sign in through the browser right from setup, and each agent says hello once it's signed in so you can see it working.

Improvements

  • Codex installs on a fresh Mac. Codex now installs with OpenAI's standalone installer, so it no longer needs npm or Homebrew.
  • Sidebar Projects / Latest switch is now optional. The switch is hidden by default and the sidebar stays on Projects. A new "Projects / Latest switch" setting brings it back, along with the mode you last used.
  • Fewer local network prompts. The computer switcher at the bottom of the sidebar only appears once Remote Access is on, or while you're viewing another Mac. Addy also no longer searches for nearby Macs until Remote Access is on, so a fresh install won't trigger macOS's local network permission prompt.
  • Project import only appears when needed. Setup searches for Git projects in the background, and the import page only appears if it finds some.
  • Start page colors. The browser start page now uses Addy's yellow.
  • New icon. The app icon was updated.

Bug Fixes

  • ⌘Q works on the access screen. ⌘Q now quits Addy while the access sheet is showing; before, it only beeped.
  • Restored terminals stay plain. Terminal panes restored from a saved layout no longer relaunch the default chat model. Only terminals that were actually running a model CLI start it again.
  • Sidebar drag crash fixed. Addy no longer crashes when a drag ends over the sidebar.
  • Browser inspector fix. The inspector no longer fails while reading React component trees that contain fragment, root or text nodes.

Internal Changes

  • Faster sync lookups. Sync now looks up projects from the list already in memory instead of reading it from disk each time.
  • Release build fix. Release scripts now ask SwiftPM where it put the universal build instead of guessing the path.
