What's New

New Features

  • Settings → Remote Access has a new "Install Addy Mobile" row for joining the Addy Mobile beta on TestFlight. Click "Show QR code" to get a code you can scan with your iPhone, along with step-by-step instructions, or use "Copy link" or "Open in browser".

Improvements

  • The "Pair a phone" section in Remote Access settings now explains that Addy Mobile finds a nearby Mac by itself. The one-time pairing code is now behind "Pair manually", for when the Mac doesn't show up, and the connection status now appears under the "Allow remote access" switch.
  • When an automatic CLI update keeps failing, Addy now waits longer between attempts instead of retrying every hour. The wait doubles after each failure in a row, up to once a day, and goes back to normal after the next successful update.

Bug Fixes

  • Failed automatic CLI updates now show the real reason they failed. Before, updaters that print their error to normal output, such as cursor-agent, showed no useful message, and the cause at the end of long installer logs like npm's could be cut off.
