What's New

Improvements

  • Model switching is now more reliable — process verification correctly detects running AI CLIs even when they're launched through wrapper scripts or nested several levels deep in the process tree
  • Model switch status messages ("Switching to…", "Now using…") are now saved in your chat history, so they persist when scrolling back or restoring a conversation
  • Context compression and compaction notices are now part of your conversation history instead of ephemeral UI-only messages that disappeared on scroll
  • Session errors (like expired connections) now appear inline in the chat as styled error messages instead of briefly flashing in the activity bar

Bug Fixes

  • Fixed a deadlock that could freeze the UI when switching models, caused by process verification waiting on a full pipe buffer before reading its output
  • Fixed model switch failure messages displaying as neutral system text instead of visually distinct error indicators
