What's New

New Features

  • Added a GitHub Actions view to the GitHub pane, next to pull requests. It lists recent workflow runs (up to 40 per repository) with their status, branch, trigger event, and duration. You can search the runs and filter them by All Runs, In Progress, or Failed.
  • Runs that failed, timed out, or were cancelled have a Re-run button, plus a "Re-run Failed Jobs" context menu item. The context menu also has Open on GitHub, Copy URL, and Copy Branch.
  • Closed browser tabs now come back. When you reopen the browser in a project, it restores the tabs from the last browser pane you closed there, including which tab was active. A browser that had only start pages leaves nothing to restore.
  • When you edit a queued message from the Addy remote app, you can now add attachments to it. Text-only edits still work with Macs on older versions.

Improvements

  • Workflow runs refresh faster while any run is queued or in progress. Clear messages cover a missing GitHub CLI, signing in again, and repositories that can't be read. If only some repositories fail, the others still load.
  • The pull request list and the Actions list now share one GitHub pane layout and header.

Internal Changes

  • Added tests for the GitHub pane and Actions state handling, and for browser tab restore.
