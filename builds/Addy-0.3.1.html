What's New

New Features

  • Auto-approve safe Claude Code tool permissions — read-only tools (Glob, Grep, Read, LSP, ToolSearch) and all Addy MCP tools are now automatically allowed during hook callbacks, eliminating repeated Allow/Deny prompts for non-destructive operations
  • Pending permission and question cards now persist across app restarts — if you quit Addy while a Claude Code session is waiting for approval, the prompt is fully restored when you reopen the conversation, with its Allow/Deny buttons intact

Improvements

  • Stale permission and question cards are automatically retired when the conversation moves on — if Claude Code continues without waiting for your answer, the outdated prompt is visually expired instead of lingering indefinitely
  • Stale code review and plan review notifications are automatically cleared when you re-trigger a review for the same target, preventing old results from piling up
  • Permission/question cards now appear above any active tool batch group (e.g. "Searching…") instead of being buried underneath it
  • Right-clicking pane headers now reliably shows the context menu everywhere in the header bar — previously, clicks on certain areas were swallowed by the window drag region

Bug Fixes

  • Fixed system messages and error messages not rendering when restoring saved chat conversations — these blocks now display correctly on reopen
  • Fixed telemetry not forwarding info/warning/error-level logs to the dashboard (debug logs remain excluded as intended)
