What's New

New Features

  • Project icons can now be picked from a searchable SF Symbol picker. Choose one from the sidebar's project menu or from Project Health.
  • Added a Close All Panes command (Cmd+Option+W) in the View menu. It closes every pane in the active split and starts a fresh agent in your default agent mode.
  • Agents can now build custom pane types that draw the same chevron as Addy's built-in panes. The MCP tools and IPC handler for custom panes were extended to support this.

Improvements

  • The Project Health view was reworked to share the new icon picker, and the sidebar's project icon handling was updated to match.
  • Custom panes now use the same chevron shape as the rest of the app, so pane headers look consistent.
  • Close All Panes appears in the Panes category of the keyboard shortcut settings, so you can rebind it.

Bug Fixes

  • Fixed the default agent mode being stuck on Terminal for settings saved by older versions. Those settings now reset to Chat once, and a Terminal default you choose afterward is kept.
