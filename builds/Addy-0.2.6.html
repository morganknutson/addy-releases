What's New

New Features

Improvements

  • Theme-driven chat typography — Chat font sizes and spacing are now controlled by your theme rather than hardcoded, so custom themes can adjust text size and layout density across all chat elements.
  • Dedicated thinking block rendering — Thinking blocks now use their own markdown renderer with independent font and color settings, separate from regular message text.
  • Taller multiline prompt field — The chat composer's multiline input now shows up to 8 visible lines (up from 5) before scrolling, giving you more room to compose longer messages.
  • Light theme polish — Adjusted pane borders, footer backgrounds, card hover borders, and chat background colors in the light theme for better contrast and consistency.

Bug Fixes

  • Fixed Codex chat duplicating text — The Codex stream parser was emitting the same text twice when an item.completed event repeated text already sent during item.started. Text is now deduplicated per block.
  • Fixed chat blocks stuck in streaming state — When the model finished a message without explicitly closing its content blocks, text and thinking blocks would remain incomplete. Open blocks are now finalized automatically when the message ends.
  • Fixed empty assistant messages briefly flashing — Whitespace-only text blocks (common during streaming) were incorrectly treated as visible content, causing empty message wrappers to appear and create visual gaps.
  • Fixed CloudKit sync race condition — Concurrent access to the pending saves/deletes state could cause data corruption during sync. Added proper locking to serialize access from multiple threads.
  • Fixed multiline prompt field scroll position not resetting when content shrinks back below the maximum height after deleting text.
  • Fixed multiline prompt field text layout not properly updating its frame height after content changes, which could cause clipping or extra whitespace.
