What's New

Improvements

  • Collapsed pane rails now open only when you ask. Double-click a rail or press ⌥R to expand it, and click it to peek at its contents. Dragging a divider no longer opens a rail by accident, and resizing the window no longer pops rails back open on its own. If a split is left with nothing but rails, one still reopens automatically so the split stays usable.
  • Dragging a divider next to a rail now pushes the rail along at its strip width and resizes the full pane on the other side. A column that was dragged shut reopens as one unit, and a column made up only of rails now takes up one rail's width instead of a full pane's share.
  • The sticky project header at the top of the sidebar now works like the row it covers. You can drag it to reorder the project, drop files or items onto it, ⌃-click it for the context menu and ⇧-click it to extend the selection. It also follows selection and row changes correctly, and VoiceOver no longer reads the project twice.
  • When the sidebar is narrow, the worktree selection bar shows icon-only Hide and Delete buttons instead of holding the sidebar open.

Bug Fixes

  • You can drag the sidebar down to its minimum width again. Long project names and the worktree selection bar no longer keep it wide.
  • Removing a worktree now works even if you haven't opened its parent project's workspace since launching Addy. Before, it failed with "No git provider for parent project".

Internal Changes

  • Releases are now built on a self-hosted Mac runner, and the release DMG is built with dmgbuild so it works on a headless machine.
  • Removed unused language-server protocol types.
