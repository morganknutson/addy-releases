What's New

New Features

  • Run GitHub Actions workflows from Addy. The Actions tab in the GitHub pane has a new Run Workflow button for any workflow with a workflow_dispatch trigger. Pick a branch or tag and fill in the workflow's inputs; Run stays disabled until every required input is valid, and the form explains any refusal from GitHub without losing what you typed. Past runs offer "Run Workflow Again…".
  • Move an agent to another project by dragging its pane onto the sidebar. The project row it would land on highlights while you drag. The agent and any sub-agents it started move together, resuming their sessions in the new folder, and a move requested mid-turn waits until the agent is idle.
  • Agents can move themselves into a worktree or another project without switching your view. If the move leaves behind a starter chat you never used, Addy closes it.
  • Pasting a worktree into the chat composer attaches it as a worktree card showing its name and branch. Sending the message connects the worktree to that agent.
  • Support for Claude's /goal. The goal shows as a pinned card in the chat, and the transcript records when it is set, when a check finds it unmet, and when it is cleared. The goal is kept across relaunches. Start Goal… and Loop… are also available from the new Agent Tools menu.
  • Skills and agent commands become chips in the composer. They appear as colored pills with their icon, and skills and tools use different colors so you can tell them apart at a glance.
  • Send feedback from inside the app. Use Feedback → Send Feedback… to choose a kind, write a message and send it. If sending fails, you can resend without the report being duplicated.
  • Quota card under usage checks. When an agent checks model usage, the provider's quota card from the Model Usage pane appears under the tool card and keeps updating while it's on screen.

Improvements

  • Worktree connections now apply to one agent. Connecting a worktree affects only the agent pane you connect it from, not every agent in the project. Worktrees granted to the whole project still count for all of its agents.
  • Reworked pane menu
  • Pane colors are shown inline.
  • The new Agent Tools submenu carries the running CLI's logo, and the old Tools item is now "Addy Tools".
  • Paste Worktree or Connect Worktree… sits with the workspace items.
  • Pin, Collapse to Rail, Pop Out to Window and Return to Workspace are grouped just above Close.
  • Servers popover. Servers now open in a popover with inline Start/Stop, Show Pane and Open Page buttons. Rows update in place when a server stops or exits.
  • Browser pane behaves more like Safari
  • Fullscreen video works, including YouTube's fullscreen button.
  • AirPlay is enabled.
  • Sites receive a Safari user agent instead of a degraded page.
  • Pages animate at your display's full refresh rate instead of being capped near 60 fps.
  • The browser stays smoother on busy pages.
  • Browser tab and URL field
  • Browser tabs take their tint from the top edge of the visible page.
  • Opening a new tab puts focus in the URL field.
  • Menu bar
  • The dropdown reopens on the tab you last used.
  • The menu bar meter follows the selected Usage tab.
  • The Usage tab has a compact quota summary with pace lines, cost tiles, credits, and Refresh / Open Model Usage buttons.
  • Work board's Done section
  • You can page through older finished items with Show more / Show newer instead of losing everything past 15.
  • It no longer builds every finished card up front.
  • Plan descriptions render as proper documents and no longer repeat the card's own content.
  • Shared Markdown editor and renderer
  • The Notepad is built on Scribl's shared Markdown editor, and Memory docs use the live editor.
  • Skills, plans, Linear, the manual and previews render with the same Markdown renderer.
  • Code and plan reviews redesigned
  • Reviews were rebuilt with the standard content sections, and progress dots now sit beside the review's title.
  • Finding details are only prepared when you open them.
  • Permission and question requests and connection notices were redesigned to match the rest of the chat.
  • Panes use their own icons everywhere they appear, and redundant headings were removed from the Conversations, Model Usage, Plans and Tests panes.
  • Empty states and sign-in: empty states stay centered in their list, and Linear's sign-in is now an empty state.

Light theme

  • The bundled light palette was retuned, and controls now blend with the fill of the surface behind them.
  • Rails are drawn as a single raised surface with their title and controls. Squeezed rails shorten their titles instead of breaking the layout.
  • Agent-link plug: collapsed (railed) panes now show it, and agent links can end there.
  • Terminals now run as xterm-256color.

Element inspector

  • Its property list now scrolls.
  • What's New has new splash and vertical mockup transitions, plus manual topics for Goals, Sources & Playbooks, and Notepad.

Bug Fixes

  • Fixed a crash when reading output from git processes.
  • Browser downloads no longer freeze the app for seconds. Files are saved to a private folder first and then moved into ~/Downloads in the background.
  • Closing the main window no longer destroys it, so it comes back correctly when reopened.
  • Fixed several main-thread hangs
  • Large tool output in remote transcripts is now trimmed without scanning the whole text.
  • Remote polling no longer converts entire chats on every tick or resolves every worktree path each time.
  • The conversation index is saved in the background.
  • Chat scrolling and resizing are smoother: reloading rows and re-anchoring no longer force a layout of the whole window, and width changes wait for AppKit's layout pass.
  • The Tests pane only rebuilds rows that changed during live progress and keeps existing suite sections in place, so large test runs stay responsive.
  • The browser's network log no longer slows down on pages that make many requests to the same URL.
  • Fixed layout problems
  • Attachment tiles keep their size with long file names, and the composer's attachment strip fits its items.
  • The composer leaves room for the send button.
  • Nested cards expand to the right height.
  • Section chevrons are hidden when there's nothing to collapse.
  • When a row overflows, the layout solver can now close a whole column instead of leaving the panes squeezed.
  • A focused text field now uses the theme from the start, not only after the first keystroke.
  • Menu bar Usage buttons now show a fallback icon when their own icon is missing.

Removed

  • The Figma pane and built-in Figma integration were removed, including their settings and agent tools.
  • The Release Notes pane was removed.

Internal Changes

  • Hang detection now measures from an unanswered main-thread ping, for more accurate freeze reports.
  • Onboarding now records which step people reach and where they leave.
  • The telemetry device name is looked up once, off the main thread.
