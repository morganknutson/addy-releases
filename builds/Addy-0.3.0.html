What's New

New Features

  • Context compaction for chat sessions — when a conversation approaches the model's context limit, Addy automatically summarizes the history and starts a fresh session with full context preserved, keeping long conversations going without losing work
  • "New conversation" button at the top of the Conversations pane for quickly starting a fresh chat session
  • Claude Code control protocol handshake — Addy now registers a PreToolUse hook at session start, enabling the Allow/Deny permission prompt UI for tool calls
  • Design token scanner now parses Swift struct files (e.g. Theme.swift, Colors.swift) and categorizes static properties as color, typography, or spacing tokens

Manual compaction

  • Use the Compact action in a chat session's context menu to trigger context compaction on demand, not just at automatic thresholds

Improvements

  • Terminal auto-scroll no longer yanks the viewport to the bottom while you're scrolled up reading output — new output accumulates quietly until you scroll back down (SwiftTerm fork fix)
  • Chat errors now appear as inline styled cards in the message stream instead of overwriting the activity bar, making them easier to read and preserving conversation flow
  • Thinking block durations are now accurate — they reflect actual model thinking time rather than wall-clock time from when the event was processed, and persist correctly when conversations are restored
  • Pane splitting is significantly faster for cross-direction splits (e.g. splitting horizontally inside a vertical stack) — the view is now restructured incrementally instead of tearing down and rebuilding the entire hierarchy
  • Conversations pane now infinite-scrolls instead of requiring a "Show More" button, starts narrower (280pt), and always shows saved/pinned conversations regardless of branch or page cutoff
  • Git staging and unstaging operations now automatically retry when encountering index.lock conflicts, with stale lock file cleanup and user-facing error toasts when retries are exhausted
  • Pane names set via the header label now sync to conversation records, so renamed panes show the correct title in the Conversations list
  • The thinking block chevron is now positioned to the right of the label text instead of the far left, making it easier to click
  • Chat message slide-in animation now fires after scroll positioning, preventing messages from briefly appearing at a stale scroll offset
  • Minimum pane width increased to 160pt for horizontal splits to prevent chat tool cards and pane headers from becoming unsatisfiably narrow
  • Toast notifications now support a bottom-center position with slide-up animation, used for git mutation error messages
  • Popover menu rows now correctly highlight both label and icon text as white on hover
  • Sub-agent connector lines update their color when the system appearance changes
  • Architecture description generation now bails out of a batch after consecutive CLI failures instead of continuing to retry every file
  • Background CLI processes (plan reviews, architecture describer) now use the full discovered binary path instead of bare command names, fixing "command not found" on machines where AI CLIs aren't on the default PATH
  • Chat store writes are now coalesced and flushed on app quit, reducing disk I/O during active sessions
  • Theme card previews in the theme switcher are now fully driven by theme metrics and update in real time when editing the theme
  • Main agent panes no longer get "(done)" appended to their name when they go idle — only sub-agent panes do

Bug Fixes

  • Fixed chat stop button and Escape key not working for Codex app-server sessions when pressed before the turn ID arrived — the interrupt is now queued and delivered as soon as the turn ID becomes available
  • Fixed tool caller pane resolution silently drifting to the wrong terminal when an explicit pane ID was stale or when lastActiveTerminalPaneId took priority over the currently active agent pane
  • Fixed compaction card layout not respecting themed edge insets and timestamp font size not being independently themeable
  • Fixed session resume failures (expired Codex threads) showing a generic error instead of automatically recovering — Addy now triggers compaction recovery to start a fresh session with summarized context
  • Fixed localhost proxy server leaking dispatch sources when a proxied connection completed — sources are now cancelled after their final read
  • Fixed the commit button in the Git pane being visible before any commit message is typed — it now only appears once text is entered
  • Fixed lazy-loaded older chat messages showing empty wrappers (gaps) for tool-only assistant messages — the same visibility check from the live path now applies during scroll-back loading
  • Fixed adjustSubviews() being called on existing split views during redistribution, which could undo even divider distribution set by setPosition()
