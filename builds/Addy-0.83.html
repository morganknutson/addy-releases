What's New

New Features

  • Typing something that isn't a web address into the browser pane's URL bar now searches Google, like Safari and Chrome. For example, "swift async let" or "hello" opens search results.

Improvements

  • The URL bar now recognizes more kinds of addresses. Domains such as example.com load over https. Localhost, [::1], IPv4 addresses such as 192.168.1.20, and hostnames with a port such as devbox:8080 load over http. Addresses like about:blank load as typed.
  • Search terms are encoded safely, so queries such as "c++ & rust?" reach Google intact.
