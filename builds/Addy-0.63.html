What's New

New Features

  • Added a built-in code editor pane. You can now open and edit source files directly inside Addy with line numbers, a gutter, and language-server–backed hover and go-to-definition, without leaving the workspace.
  • Added a Project Setup pane that scans a project's readiness (dependencies, worktrees, environment) and offers one-click setup actions. Setup steps are captured as reusable "recipes" with dependency ordering, and can be run by an agent from an inline prompt.
  • Added an active repository scope for multi-repo projects. You can pick which repository is "active," and terminals, Git actions, and agent commands are scoped to that repo.
  • Added drag-to-reorder for panes — grab a pane's chrome and drag it to move or reorder it within the split layout.
  • Added a "Reopen Closed Pane" command (Cmd-Shift-T) that restores the most recently closed pane.
  • Added the ability to queue messages while a chat response is still generating, and to edit those queued messages inline before they send.
  • Added runtime model and reasoning-effort controls to chat. You can switch models and pick a reasoning effort (low through max, where supported) mid-conversation, with options discovered from the installed CLI's model catalog.
  • Added Git change attribution to agent sessions, so changes made during a run are linked back to the agent session that produced them.
  • Added manual plan approval from the plan card's right-click context menu.
  • The Tasks pane is now available in production builds.

Improvements

  • Redesigned the Tests pane around structured test output, with clearer per-test results, pass/fail parsing, and status reporting.
  • Redesigned the Git pane with line-level diffs and improved layout.
  • Linear data now loads by scoped pages for faster, more responsive issue browsing, alongside broader Linear view improvements.
  • Codex models now expose their metadata and CLI profile options, so Codex-specific settings (like reasoning effort) are handled correctly.
  • The model picker now hides CLI model profiles that aren't actually available and falls back to an available default chat profile when selecting a model.
  • Deleting a memory now asks for confirmation before removing it.
  • Notepad now sanitizes pasted text to strip unwanted formatting and control characters.
  • Refreshed onboarding with a takeover flow and smoother book-shell page transitions.
  • Numerous layout and polish fixes: centered the Git commit button, corrected server start icon rotation, fixed pane launcher row alignment, added spacing between action button icons and titles, and preserved selected-card styling across hover and theme changes.

Bug Fixes

  • Fixed terminal rendering corruption, scrollback glitches, and breakage that occurred when an agent CLI exited. Terminal frames are now clamped to a minimum size, and the app survives split-view layout exceptions during pane drags.
  • Automation/agent input sent to a terminal no longer yanks the view out of scrollback while you're reading history.
  • Stuck terminal state is now only reset after the agent CLI actually exits, avoiding premature resets.
  • Fixed multi-repo Git pane accordion behavior and layout issues.
  • Fixed pane resize behavior and now honors the sizing policy for build and terminal panes, keeping owned child panes contained within their parent columns.

Internal Changes

  • Simplified the built-in browser by removing the Direct/Compatibility mode split and the localhost proxy server (~2,500 lines removed); localhost sites now load directly.
  • Removed an ineffective localhost CSP/HSTS header rewrite rule list from the browser.
  • Project recipes and setup data now sync across your devices via CloudKit while keeping local project files protected.
