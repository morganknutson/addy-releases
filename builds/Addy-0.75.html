What's New

New Features

  • Redesigned browser and editor tab strips share one new tab component. The browser also gets a raised look, a header overflow menu, clickable URL bar behavior, and a new animated shader start page.
  • The theme editor and the theme previews in Settings have been reworked, and the bundled theme defaults are updated.
  • Local code and text file links in chat messages now open in Addy's editor.
  • Capped agent directives are now injected into every agent session, and the knowledge sections in the Memory view have new labels.
  • Antigravity chats now show MCP tool calls correctly, and Addy rescans the available models after you sign in.

Improvements

  • Chat history is now stored as one file per conversation, so large histories load and save faster.
  • Hidden projects release their chat transcripts once they pass a memory budget and rebuild them when you show the project. This lowers memory use.
  • Restoring many chats at once is faster. Per-row layout is deferred during batch restore, and restores now start before the cache warms.
  • Chat images decode off the main thread as thumbnails sized for display.
  • Chat text views use a fixed clip view, which avoids extra work on every frame change and makes chat scrolling and resizing smoother.
  • Each project's repository environment is cached instead of being resolved for every pane, so new panes open faster.
  • CSS edits made in the element inspector are written back to your source files, including CSS modules.
  • The inspector popover now closes when its browser pane is hidden or detached.
  • Highlighted pane strip resize gap on hover and while dragging.
  • Agent color swatches are now ordered yellow, orange, red, purple, blue.
  • The inspector edit badge now matches the shape of the Addy logo pill.
  • Server footer buttons stay pinned to the trailing edge when the curtain chevron is hidden.
  • Updated the Liquid package for the click-to-replay logo variation.
  • Clicking a file path link in chat now reveals the file in Finder with it selected, and link clicks are logged.
  • Memory search runs off the main thread, and memories are no longer re-embedded on every launch.

Bug Fixes

  • Fixed a hang when dragging a pane to a new spot in the layout.
  • Removed main-thread blockers in caller lookup and the Plans pane, which fixes occasional freezes.
  • Various small fixes to settings, the sidebar, and pane strip layout.
