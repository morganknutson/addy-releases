What's New

New Features

  • Context compression recovery — When Claude Code compresses your conversation context mid-session, Addy now detects it automatically, shows a system message explaining what happened, and sends a recovery prompt summarizing your recent conversation so the agent can pick up where it left off. A second compression suggests starting a fresh conversation.
  • Context usage gauge — A new progress bar in the chat footer shows how much of Claude's context window you've used (e.g. "42k/200k"), turning yellow at 65% and orange at 85% so you know when compression is approaching.

Improvements

  • Attachment previews in sent messages — Images and files you attach to a chat message now appear as inline chips in the message bubble after sending, so you can see what was included in each turn.
  • Richer attachment previews in the composer — Pasted images now show an actual thumbnail preview instead of a generic file icon, and file attachments display a themed document icon with the file extension label.
  • Hover-to-reveal remove button on attachment chips — The remove button on file attachment chips in the composer is now hidden by default and smoothly fades in on hover, reducing visual clutter.
