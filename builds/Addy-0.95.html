What's New

New Features

  • When a Claude chat is given a /goal, a goal button now appears in the pane's footer. Hovering over it shows the condition the agent is working toward. Clicking it shows whether the goal is Working or Paused, how many checks have come back unmet, and the evaluator's reason from the last check, with a Clear Goal button to stop it.

Improvements

  • If you remove several worktrees at once and one has uncommitted changes, the warning now offers "Remove All" and tells you how many more are queued. Choosing it removes the rest without asking again for each one.
  • Closing a pane now moves focus to the pane next to it in the same split, or the nearest pane before it. Focus no longer jumps to the first pane in the window, and open panes get focus ahead of collapsed rails.
  • A collapsed rail dragged into a different split now turns to match that split's direction. For example, a horizontal strip dropped into a row becomes a vertical rail instead of stretching a full pane wide.
  • Dragging a column shut now turns any horizontal strips already in it into vertical rails, so the column closes cleanly.
  • Tooltips across Addy now use Addy's own tooltip style instead of the native macOS one. This covers chat, connectors, the editor, the theme editor, settings, plans, tests, tasks and the browser.

Bug Fixes

  • Tooltips that change often, like status and progress indicators, now just update their text instead of being rebuilt on every refresh.
