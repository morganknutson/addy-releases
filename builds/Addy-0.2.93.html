What's New

Agent Permission Prompts in Chat

  • When an agent needs permission to run a tool (Bash, Edit, Read, etc.), an inline card now appears in the chat with Allow and Deny buttons — no more silently auto-accepting everything
  • Permission cards show the tool name and a description of what it wants to do (e.g., the command to run, or the file to edit)
  • Supports freeform question prompts too — when the agent asks a question, you get a text field to type your response
  • Unanswered permission requests expire and grey out when the session ends
  • Permission history is fully persisted — you can see what was allowed or denied when reopening a conversation

Animated Send/Stop Button

  • The send and stop buttons in the chat input bar have been unified into a single animated button — sends when idle, shows a bouncing dot animation while the agent is working, and reveals a stop button on hover

Improvements

Chat

  • MCP tool calls now show human-readable names instead of raw identifiers (e.g., "Navigate" instead of "mcp__addy__addy_browser_navigate")
  • Tool blocks in expanded tool groups now stretch to full width instead of bunching up on the left
  • Send button now enables when you have image attachments queued, even without text
  • Activity status label shows "Waiting for your response..." when the agent is blocked on a permission prompt

Conversations Pane

  • Pinned conversations now appear in their own section at the top with a pin icon
  • Background agent conversations (sub-agents, code reviews, plan reviews) are now hidden from the list to reduce clutter
  • Conversation titles are backfilled from pane names so they stay meaningful

Activity Indicators

  • Pane activity indicators moved from the header bar to the bottom-center of each pane, keeping headers cleaner
  • In chat panes, the animated action button replaces the header indicator — no more duplicate activity signals

Bug Fixes

  • Fixed Cmd+V paste in terminal panes silently failing on macOS 14+ — paste was reading the clipboard on a background thread where it could return nil
  • Fixed pinned and snapshot flags being lost when conversations were synced to disk
  • Fixed Gemini conversation discovery showing stale sessions with "Just now" timestamps when dates couldn't be parsed
  • Fixed thinking blocks not resizing properly after theme changes
