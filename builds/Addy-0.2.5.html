What's New

New Features

  • Chat attachment support — You can now drag and drop or paste files and images directly into the chat composer. Attachments appear as previews above the input field before sending.

Improvements

  • Smarter tool groups in chat — Tool call groups now auto-expand while tools are running and show a live "Running N tools…" status. When all tools finish, the group automatically collapses after a short delay.
  • Faster project switching — Chat pane restoration is now deferred until after the window renders, so switching to a project with open chat panes feels significantly snappier.
  • Hardened Codex chat sessions — Codex chat turn completion now tracks per-message state, buffers stderr, and properly handles edge cases like process exits before stream completion, reducing stuck or blank chat turns.
  • Multiline chat composer rewrite — The chat input field now uses a proper text view with multiline editing, correct cursor positioning for unicode text, and support for paste and drop handlers.
  • Codex profile flag passthrough — Codex chat sessions now correctly forward model overrides and configuration flags (like --profile, --sandbox, --config) from your model profile commands.
  • Test runner pane ownership — When an agent triggers a test run, the Tests pane is now owned by and anchored to that agent, keeping test results associated with the pane that requested them.
  • Resilient chat conversation loading — Saved chat conversations now decode gracefully when fields are missing or have unexpected casing, preventing blank chat restores after updates.
  • Model profile deduplication — Duplicate built-in model profiles (e.g. multiple GPT-5.4 entries) are now automatically detected and cleaned up on launch.

Bug Fixes

  • Fixed pane corner radius highlighting not tracking the focused pane correctly when switching between panes — the selection indicator now updates reliably.
  • Fixed plan card titles getting clipped when hovering over action buttons — the header content area now adjusts its trailing constraint based on which trailing view is visible.
  • Fixed Cmd+click path injection in the file explorer not working when the row was already selected — the action now fires from the click handler instead of the selection delegate.
  • Fixed sidebar activity indicators showing stale state — they now reflect actual agent activity by polling the real pane model state.
  • Fixed sub-agent connector arrows flickering between directions — the arrow now uses the dominant center offset between parent and child panes for stable positioning.
  • Fixed background review agents getting permanently stuck — a 5-minute watchdog timer now fails wedged review processes so the parent agent can continue.
  • Fixed LSP diagnostics callback firing on a background thread, which could cause UI glitches in the footer status bar.
  • Fixed git snapshot operations not validating project paths before launching git, which could cause crashes with malformed paths.
