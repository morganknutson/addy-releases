What's New

New Features

  • Added multi-repository project support. Projects containing multiple Git repos now detect and manage them automatically — the Git pane shows an accordion view with each repository as its own expandable section, complete with independent staging, committing, and branch management.
  • Added a model catalog that discovers available models from installed CLI binaries (Claude Code, Codex). A new "Available models" section in Settings shows all discovered models with a Refresh button. The model picker now includes catalog-discovered models alongside custom profiles.
  • Added one-click cloud project download. Projects synced from other devices via iCloud now show a "Download to This Mac" button that clones the repository into the same home-relative path as the originating device.
  • Added addyruncommand MCP tool for running finite shell commands in their own visible terminal pane. The tool blocks until the command exits and returns the exit code plus output tail — filling the gap between native Bash (invisible) and addystartserver (persistent).
  • Added MCP tool call approval UI for non-Addy MCP servers. When an agent requests a third-party MCP tool, Addy now shows an Allow / Allow for session / Deny permission card instead of silently declining.
  • Added an in-app manual with illustrated pages covering the sidebar, panes, agent workflows, plans, and memory. The manual opens automatically during onboarding and is accessible from the sidebar help button.

Improvements

  • Onboarding streamlined to three steps (Welcome, Dependencies, Agent CLIs) and now includes a "Say hi" button that lets each newly installed CLI greet the user with a one-shot message.
  • Project knowledge (memories, context, architecture docs) moved from the in-repo .addy/ directory to an app-owned knowledge store, keeping project repositories clean. Existing .addy/ directories are migrated automatically.
  • Cross-device project sync now includes sidebar order, chat conversation history, and worktree branch names — so your workspace layout transfers between Macs.
  • CloudKit sync engine reworked to avoid re-entering main-thread-only stores from background callbacks, and to deduplicate pending record zone changes.
  • Pane mutation notifications (split/resize) now scope to the affected view hierarchy instead of triggering relayout across every chat and diff view in every project, improving responsiveness during multi-pane edits.
  • Context window sizes are now resolved from the refreshed model catalog instead of a hardcoded lookup table, so new models are recognized without an app update.
  • System theme mode now debounces redundant appearance change notifications, preventing unnecessary relayouts when macOS sends duplicate updates.
  • macOS Dictation no longer causes lag in the chat composer — text-driven resizes are now applied immediately without animation.
  • Chat scroll view and table view no longer show a focus ring.
  • Settings window height increased to accommodate the new model catalog section.
  • Git tools (addygitstatus, addygitbranches, addygitcheckout) now accept repositoryid and repositorypath parameters for targeting specific repos in multi-repo projects.
  • addynotifypane can now send messages to panes in other open projects.
  • Pane list IPC encoding switched from dictionary-based JSONSerialization to a typed Codable struct for consistent key ordering.

Bug Fixes

  • Fixed a data loss scenario where terminating the app with an empty in-memory sidebar would overwrite a valid persisted project list. Addy now skips the save when the sidebar is empty but the persisted file is not.
  • Added automatic backup and recovery for project and pane layout data. Both SessionStore and PaneStore now write a .bak file before each save and recover from it if the primary file is missing or corrupt.
  • Fixed cross-project MCP tool routing where an implicit sourcepaneid from the calling pane could override an explicit project_path, causing operations to target the wrong project.
  • Fixed MCP permission cards not recognizing the "Allow for session" response variant, which could show "Denied" text instead of "Allowed for session."
  • Fixed chat model picker not showing catalog-discovered models by switching from raw modelProfiles to availableModelProfiles().
