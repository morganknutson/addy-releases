What's New

Pull Requests inbox

  • A new repository-scoped Pull Requests pane lists open PRs for the current repo, with built-in filters for PRs you authored and PRs awaiting your review, and lets you check out a PR into its own worktree without disturbing your working tree.
  • Network activity pane for the browser â€” The built-in browser gains a Chrome DevTools-style network log with resource-type filter chips, a DevTools-style filter syntax, "Copy as cURL," request resend, and full request/response capture. Agents can inspect this traffic through a new MCP tool.

Customizable keyboard shortcuts

  • A new Settings â†’ Shortcuts tab lets you rebind View, Pane, and Tool actions (splits, pane focus, toggling Files/Tests/Plans/Git/Browser, font size, full screen, and more), with your overrides synced across devices.

Agent folder access

  • Grant agents access to folders beyond the project directory, either project-wide (inherited by every agent) or scoped to a single pane. Grants are passed through to the Codex, Gemini, and Claude backends.

Agent pane references

  • Insert other panes into the composer as reference chips; agents can send messages directly to a referenced pane, and reference chips are clickable to jump to that pane.

Skill autocomplete

  • Typing a skill in the chat composer now surfaces an autocomplete popover that stays open as you type.

Live agent work awareness

  • When multiple agents run concurrently, each is informed when another agent is already working on the same files, with conflict-aware coordination to reduce clobbered edits.

Improvements

  • Refined the onboarding shell flow and animations, including a new "Ready" step.
  • Polished the Settings window and agent activity controls.
  • Pane footer colors now persist across restarts, and can be cleared via the footer's right-click menu.
  • Theme defaults are now bundled as JSON with a simplified theme editor.

Voice input polish

  • Improved microphone layout, updated voice-button theming and active-state styling, and a higher-quality multifunction speech decoder bundle.
  • Agent-owned test panes now close automatically when the run completes.
  • Promoted launcher items and fixed task-list theming.
  • PR review worktrees are now excluded from workspace sync, and usage gauges are tinted to match their pane color.
  • Agents no longer write to AGENTS.md or CLAUDE.md, and agent connector arrows are disabled by default.

Bug Fixes

  • Fixed chat links opening in the docked browser instead of the intended target.
  • Fixed conversation pane titles not appearing correctly on launch.
  • Fixed the context gauge disappearing when a pane's color changed.
  • Fixed a stale single-repo Git pane failing to refresh.
  • Fixed the layout of attachments on queued messages.
  • Pull request remote URLs are now redacted in display to avoid leaking private remote details.
