What's New

Your Other Macs

  • Click the computer switcher at the bottom of the sidebar to open another Mac's Addy in this window, with its projects, chats, terminals, Git, Plans and other panes. Macs signed into your iCloud or Addy account connect straight away. Any other Mac must be approved by matching a pattern and words on both screens. Browser panes and localhost dev servers are forwarded so pages load as they would on that Mac.
  • Settings → Addy Mobile is now Remote Access and covers your other Macs as well as your phone. Turn on Allow remote access there on the Mac you want to reach.

Orchestration

  • An agent pipeline that takes GitHub issues, Linear issues, Addy tasks or new tasks all the way to a pull request. Each item gets its own worktree and agent, then checks and an agent review, and moves through Implementing, Validating and Revising until it's ready to merge. Addy can also merge it for you once it's green and reviewed.
  • The Orchestration board includes a workflow builder with playbooks, rules and quota-aware routing. Items that need you collect under Needs you, and open Addy tasks can be picked up automatically.
  • ⇧⌘O

Linear pane

  • Connect Linear, browse issues (including ones that aren't in any project), and click Start work to send an issue through the pipeline or Build to work on it in a new agent chat.
  • Model Usage pane and menu bar meter: see live session and weekly limits for each provider, your pace ("in reserve" or "in deficit") and costs priced from Claude and Codex session logs. Addy alerts you at 80% and 95% and when you're on pace to run out. You can add Anthropic or OpenAI admin keys to see API spend.
  • Addy can keep running in the menu bar after you close its last window. The menu bar dropdown has Agents, Orchestration and Usage tabs and shows an amber dot when an agent is waiting on you.

Skills pane

  • Browse skills.sh, install skills for one project or for all of them, and use them with / in any chat (Codex uses $). Every installed skill now works with every agent Addy runs.
  • Tasks pane is now in release builds. It has a chat-style composer that accepts pasted and dropped images, plus an Active/Completed toggle.
  • GitHub pane is now in release builds. It lists pull requests and Actions runs, and you can now merge a pull request right from the pane and choose the merge method.

Steering

  • Click Steer on a queued message to send it into the turn that's running, without stopping the agent. Messages other agents send to a busy chat are steered in the same way.
  • You can change Claude's thinking level and fast mode on a live session; the change applies from the next turn. Models, thinking levels and fast mode now come from Claude Code's own catalog.
  • Added Meta's Muse Code as an agent backend. You can install it and sign in under Settings → Models.
  • Voice input and read-aloud are now in release builds, with Kokoro and Qwen3 as local text-to-speech models. You can stop a reading from its message or from the pane header.
  • A new Latest mode in the sidebar lists recent agent work first instead of grouping branches under their projects.
  • Agent builds that share a build folder now wait in a queue instead of colliding. A waiting build shows the whole queue.
  • Shift-Command-R in the browser clears the site's cache and reloads the page.
  • Open in Addy and Remix in Addy links on addy.land now open those apps directly in Addy.
  • The Element Inspector's Rewrite first tries Apple's on-device model for simple text edits. It hands the edit to a cloud agent only when it can't apply the rewrite safely.
  • The What's New spotlight now plays live scenes of the real UI, has a Past Updates view, and the manual gained topics for Your Other Macs, Orchestration, Linear, Skills, Model Usage, the menu bar, Voice, Steering and Models.

Bug Fixes

  • Fixed many app hangs found by hang reports, including in
  • Huge Git working trees and commit histories, which now page in rows
  • Section and conversation lists, which reuse rows instead of rebuilding them

  • Chat retiling, which now skips off-screen and collapsed panes

  • Launch no longer blocks on the Keychain or on statting every project. Pipeline snapshots, connector credentials, and Addy tasks are now read and written off the main thread.
  • Quitting can no longer hang on a Keychain flush.
  • Pipeline commands can no longer starve Addy's agent communication and deadlock, and storms of git and gh processes are throttled.
  • Concurrent token refreshes no longer sign connectors out, and Linear no longer looks disconnected while it's still signing in.

  • Question cards can still be answered after their CLI has exited, and Stop now cancels pending sends.
  • Chat sends survive navigation, and chats no longer jump to a new scroll position during pane changes or while hidden.
  • The workspace window keeps its launch size instead of resizing after its content loads.
  • The sidebar keeps scrolling up while a drag hovers over the sticky project header.
  • Headless pipeline workers no longer open web pages.
  • Earlier worker logs are rebuilt from disk after a relaunch.

Internal Changes

  • Crashes are now captured with KSCrash and uploaded with hangs and MetricKit diagnostics to telemetry.addy.md, and release dSYMs are uploaded so crash reports show symbol names. Crashes of child processes are no longer filed as Addy crashes.
  • Pipelines, skills and model usage now sync across your Macs through iCloud.
