What's New

New Features

  • Blueprint cards in the Project pane can be reordered. Drag the grip on a card's header to move it, and the new order is saved. The grip only appears when a project has more than one Blueprint.
  • Each Blueprint card has a collapse/expand button that shrinks it to its header. Addy remembers the choice per Blueprint on this Mac.

Improvements

  • The browser on your phone now gets its own phone-sized web view on the Mac, so the browser pane on the Mac no longer changes while you use it from your phone. It follows the Mac pane's active tab and can show either a mobile page or a desktop-style page sized to your phone's screen.
  • Taps and typing from your phone reach the page as real mouse and keyboard events. This makes sign-in forms inside cross-origin frames work, and sites that check for genuine input now accept them.
  • Your phone's keyboard appears when a text field on the page has focus, including fields inside frames.
  • Browser shortcuts now take priority while a browser pane has keyboard focus. Cmd+T opens a new tab there instead of triggering the workspace terminal gesture, and Cmd+R, Cmd+W, Cmd+1–9, Cmd+Shift+[ / ], and zoom work the same way. Shift+Cmd+T remains the workspace-wide terminal gesture.

Internal Changes

  • Browser shortcut handling was consolidated into a single shared mapping, with new tests for shortcuts, Blueprint collapse, and Blueprint reordering.
