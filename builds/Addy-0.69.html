What's New

New Features

  • Fresh installs now discover their model list from the AI CLIs you actually have installed, automatically selecting the latest recommended model instead of seeding a fixed list of preset profiles. Settings marks that auto-selected model as the default and explains it in a tooltip.

Improvements

  • Truncated pane titles now show the full title on hover, both in editable pane headers and in the shared pane header bar.
  • The project browser now shows hidden files and folders such as .env and .github, and file search matches them too.
  • Sidebar project rows now display server activity, not just agent activity, so a running dev server shows up even when no model is working.
  • Successful Git pulls now confirm with a "Pulled successfully" toast instead of only surfacing failures.
  • Auto-compaction and the process window curtain now default to off, and code reviews now start collapsed by default.

Bug Fixes

  • Fixed the Memory pane reloading and re-laying out repeatedly, including redundant text measurement, so it opens and updates more smoothly.

Internal Changes

  • Removed an unused SwiftTerm dependency entry from the package lockfile.
