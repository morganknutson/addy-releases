New Features

Codex Permission Prompts in Chat

  • Codex chat sessions now show inline permission and input request cards — the same Allow/Deny UI that Claude sessions already have — instead of silently logging permission events
  • Supports tool permission requests (Bash, Edit, Read, etc.), freeform questions with custom options, and nested control requests
  • Permission responses are normalized for Codex (Allow → "y", Deny → "n") so the backend receives the format it expects
  • Gemini sessions also now show inline permission and input prompts using the same shared parser

Context Usage Gauge for All Backends

  • The context usage gauge in chat now works for Claude, Codex, and Gemini sessions — previously it was Claude-only
  • Context limits are automatically set based on the model's context window size reported by the backend (e.g., 200K for Claude, 1M for Gemini)
  • The gauge now tracks actual context window size per API call rather than cumulative billed tokens, so it accurately reflects how full the context window really is
  • Context gauge and its Clear/Compact actions are now visible as soon as a session starts, even before the first usage report
  • Token usage state is persisted across app restarts — reopening a saved conversation restores the gauge to where it was

Mid-Conversation Model Switching

  • Switching models during a chat conversation now builds a summary of the conversation history and sends it to the new model, so context carries over seamlessly instead of starting from scratch

Chat Mode for Plans

  • Plans can now be built and executed via the chat UI (not just terminal) when the default agent mode is set to chat — the "Build" button sends the orchestrator prompt directly to a new chat session
  • Creating a new plan from the Plans pane also respects the default agent mode, spawning a chat-based agent pane when configured

Theme Editor Category Navigation

  • The theme editor now has a middle sidebar that lets you filter color tokens by UI category — App Chrome, Buttons, Chat, Browser, Syntax, etc. — instead of scrolling through the entire list

Improvements

Chat

  • Pressing Escape during an active chat session now stops it, matching standard terminal behavior
  • Tool calls that run for more than 3 minutes without completing now auto-stop the session, preventing hung sessions
  • MCP tool names from Codex (e.g., "addy.addy_list_panes") are now displayed with human-readable names, matching the existing Claude format
  • Claude stream parser now includes cache creation and cache read tokens in context usage calculations, giving a more accurate picture of total context consumption
  • Card expand/collapse animations now scope layout to the card itself instead of the entire scroll view, eliminating O(N³) constraint solving stalls on long conversations
  • Chat session now properly restarts when clearing a conversation, so you can immediately send a new message

Design System

  • Added new "Surface" and "Raised" button styles to the theme system — buttons across the app (Git pane, Plans, Memory, Tests, Skills, etc.) now use the Surface style for better visual hierarchy against pane backgrounds
  • Scroll-to-bottom button now has a dedicated hover background color in the theme, replacing the hardcoded blend calculation

Terminal

  • macOS Dictation now works in terminal panes — dictated text flows through naturally without being intercepted by the key event handler
  • Added "Cut" (Cmd+X) to the Edit menu — previously only Copy, Paste, and Select All were available

Performance

  • Chat conversation store now writes to disk on a background queue with an in-memory cache, eliminating main-thread I/O stalls during autosave
  • FileIconView no longer redraws on every frame — the document icon is rendered once into a cached NSImage, eliminating redundant Core Graphics work
  • Split pane insertion now uses incremental updates when adding to an existing split, avoiding a full view hierarchy rebuild
  • Layout after pane insertion uses deferred needsLayout instead of immediate constraint resolution to avoid stalling the main thread

Other

  • The Conversations pane is now available in the pane launcher for all builds (previously debug-only)
  • Claude Code prompts passed via the toolbar now use --append-system-prompt for better context injection

Bug Fixes

  • Fixed chat appearing blank after pane view hierarchy rebuild — the scroll view's clip view could have stale bounds until the next user scroll
  • Fixed normal session stops (SIGTERM, exit code 143) being incorrectly reported as errors — "Process exited with code 143" no longer appears when you stop a session
  • Fixed chat generating state not clearing properly for Claude sessions — the session now waits for the result event to mark the true end of a turn instead of clearing on every messageStop
  • Fixed context gauge showing inflated values when restoring conversations saved before the per-call context fix — stale cumulative totals are detected and suppressed
  • Fixed file attachment preview cards using incorrect centering and aspect ratio after the FileIconView shadow padding change
  • Fixed project cleanup leaking review findings, hook activity state, and sync count dictionaries when removing a project
  • Fixed worktree sync creating phantom sidebar entries on fresh repos with only one branch
  • Fixed Codex config corruption where older Addy versions wrote array-valued notify fields into non-hooks TOML sections — the config writer now repairs these to string values
  • Fixed default branch detection falling back to "master" on fresh repos — now correctly reads the HEAD symbolic ref (e.g., "main")
