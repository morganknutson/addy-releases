What's New

New Features

  • Addy now checks access when it launches. You sign in with GitHub, and if access is paused or a required update is pending, a gate window or sheet covers the workspace until it is resolved. While access is denied, workspace menu items and agent commands are disabled. A "Check Again" button re-runs the check, and the gate offers Sign Out, Update Now and Quit Addy.
  • Agent pane footers have a new "Owned Panes" button. It lists the panes that agent spawned with their status (Working, Idle, Done, Reported or Failed), and clicking a row reveals that pane, even if it is hidden or collapsed.
  • Addy Mobile can now
  • Start new chat or terminal agents in a project
  • Create branch worktrees
  • Switch an agent's model and thinking level
  • Set an agent's color
  • Remove, edit or reorder messages queued behind a running turn
  • Addy Mobile now mirrors your Mac's model list, default models, sidebar project icons, and branch worktrees nested under each project, including branches of collapsed projects.

Improvements

  • The chat composer now has its own undo history. Inserting attachments, completing mentions and similar edits can be undone with Cmd+Z, and programmatic resets, such as after sending, no longer cause undo errors.
  • A pane's "working" indicator now clears as soon as a turn finishes, instead of lingering until a two-minute timer expires.
  • Worktrees whose HEAD is detached, such as during a rebase or bisect, are now kept in the sidebar with their panes, chats and servers. Previously they were treated as removed. During a rebase the worktree keeps its branch name.
  • Selecting a project that is already showing now only restores its sidebar highlight. It no longer re-runs the project switch, which could steal keyboard focus on every sync.
  • The model list for the Antigravity CLI (agy) is preserved when a rescan fails, for example while the CLI updates itself. It no longer collapses to a single bundled entry.

Bug Fixes

  • Fixed chat agents appearing finished while the CLI was still running queued turns, such as a message sent mid-turn or a background-task notification. Chats now stay in the generating state until the last queued turn completes.
  • Fixed iCloud sync problems
  • Overlapping sends could re-send records that were already in flight.
  • A duplicate record in a batch could stall all pending saves.
  • A server copy identical to the local one kept re-triggering conflicts.
  • Partial send failures wrongly failed the whole Sync Now.
  • Sync Now's local inventory became very slow with thousands of records, because it rewrote its journal for every record.

Internal Changes

  • Added a focus-change trace to help diagnose keyboard focus issues.
  • Remote protocol bumped to version 8.
