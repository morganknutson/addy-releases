What's New

New Features

  • New ⌘K search (View → Search Chats and Projects…) covers every project in the sidebar and every chat inside them. Project names match fuzzily and chat titles match as you type. Matches in message text appear a moment later with an excerpt, and closing the palette puts focus back where it was.
  • Chat footers can show a Commit button. It tells the agent to commit only the changes it made in that conversation, leaving other agents' and your own uncommitted edits alone, and never to push, amend, rebase or switch branches. Turn it on in Settings with the new "Commit button" toggle. The button is disabled while the agent is busy.

Improvements

  • Git history, GitHub Actions runs and Linear issue lists load more as you scroll to the end. Git history used to stop at 20 commits and Actions at 40 runs, and Linear needed a "Show more" button. If a Linear page fails to load, the reason appears under the issues with a Retry button.
  • The Done section of the work board now lists your project's full history as light rows that load as you scroll. Each row shows the item's state, source and playbook, and expands to show its details and actions.
  • In a wide chat pane, the footer and composer now float over the bottom of the transcript at a fixed width, and the transcript scrolls underneath. In narrow panes the footer stays docked edge to edge.
  • Long transcripts scroll and resize more smoothly.
  • Content is padded and spaced the same way in every pane list and scrolling pane, so sections line up from pane to pane.
  • The Git pane's Commit button now has a commit icon.

Bug Fixes

  • Model Usage no longer shows repeated Keychain password dialogs each time Claude Code updates its stored login. If Addy can't read the login without asking, the Claude card shows an "Allow Access" button, and clicking it once brings up the macOS password dialog.
  • A chat streaming in a hidden project or sub-agent pane no longer slows the whole window for seconds at a time.
  • A brief error or rate limit from a connector's sign-in server no longer signs you out of that connector. Addy keeps the sign-in and tries again on the next request; only a real rejection asks you to sign in again.
  • A Mac whose Addy data was reset no longer shows up twice in the remote Mac switcher. Its new entry now replaces the old one.
  • The remove badge on attachment thumbnails in the composer is no longer clipped, and a click anywhere near it removes the attachment.
  • A running activity chip no longer loses its animation when the theme refreshes.
