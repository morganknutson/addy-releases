What's New

Bug Fixes

  • The GitHub pane no longer says the gh CLI is missing when you open Addy from Finder or the Dock. Addy now uses your login shell's environment and also checks common install locations like Homebrew. This covers pull requests, GitHub Actions and other GitHub commands.
  • When you show another Mac's workspace, this Mac's sidebar project list and panes are now fully hidden. Before, they could show through translucent themes or take clicks. This Mac's panes keep running in the background, so switching back is still instant.
  • Switching back from another Mac returns keyboard focus to the pane you were typing in, if that pane is still visible.
  • The Ask button on Orchestration task cards now works for tasks that were already on the board when the pane opened. Before, clicking it did nothing.
