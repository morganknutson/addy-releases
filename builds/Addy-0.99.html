What's New

Bug Fixes

  • Cmd+W now closes the current browser tab even when keyboard focus has moved out of the web view, for example after a click that didn't take focus or a restored layout that focused a chat prompt. Before, it could close the whole browser pane.
  • Cmd+W in a popped-out browser window closes tabs one at a time before it closes the window.
  • A browser with only an empty start page still lets Cmd+W close the pane or window, as before.
