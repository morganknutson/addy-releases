What's New

Pop panes out into their own windows

  • Double-click a pane's header drag handle to lift it out of the workspace into a standalone window — double-click again (or close the window) to snap it back. A "Pop Out to Window" / "Return to Workspace" item was also added to the pane context menu.
  • Popped-out panes stay fully live: agents, focus, IPC, and session persistence keep working, and the remaining panes absorb the freed space instead of leaving a gap.
  • The browser remembers its pop-out window position, so an agent that closes and reopens the browser (for example to recover a broken page) won't yank it back into the workspace.

Portable project Blueprints

  • Project setup actions are now called Blueprints, and each Blueprint can be exported to a shareable .addyblueprint file from its card header, or imported from the Project pane's new "Import Blueprint" button.
  • Exports and imports are reviewed before they happen: Addy warns when a Blueprint contains absolute or machine-specific paths or values that look like credentials, and an import preview shows the action count and description before you accept it as a copy.

Reorder queued messages

  • Queued chat messages can now be dragged by their position badge to reorder them before they're sent.

Improvements

  • Server steps in a Blueprint now show a "Stop" button while their server is running, and starting a Blueprint server whose pane was previously stopped restarts it in place instead of opening a duplicate collapsed pane.
  • Right-clicking a link in a chat message adds a "Copy Link" action alongside "Copy Message".
  • Truncated pane titles now show the full name as a tooltip on hover, in both the pane header bar and inline editable pane names.
  • Sidebar project rows now show server activity, not just model activity.
  • A successful git pull shows a "Pulled successfully" confirmation toast instead of finishing silently.
  • The project file browser now lists hidden dotfiles and directories.
  • On a clean install, Addy picks its default model from the backends you actually have installed rather than shipping a fixed list, and Settings marks that auto-selected model as the current default.
  • New installs now default to collapsed reviews, auto-compaction off, and the process window curtain off.

Bug Fixes

  • Fixed the Memory pane reloading and re-laying out repeatedly, including redundant work when a reload was already in flight.
  • Fixed Blueprint command checks hanging indefinitely when a child process left inherited pipe handles open.
  • Fixed clicks in one window matching panes in another; pane hit-testing is now scoped to the window the click occurred in.
  • Closing the main window now also closes any pop-out pane windows, so the app quits properly.

Internal Changes

  • SwiftTerm is now pinned by revision rather than branch, and local SwiftPM edit-mode overrides are ignored, so builds are reproducible.
